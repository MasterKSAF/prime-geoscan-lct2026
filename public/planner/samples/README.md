# Образцы геометрии

Это маленькие модельные файлы для Демо 1, не официальные ограничения и не разрешения на полёт. Координаты — WGS84, `[долгота, широта]`.

- `flight-boundary.geojson` → «Граница полётов → Загрузить границу»: заменяет единственный разрешённый контур.
- `no-flight-zone.geojson` → «Запреты и препятствия → Загрузить запретные зоны»: добавляет постоянный запрет на всех высотах модели. Он намеренно перекрывает часть участка — проверьте изменение результата.
- `reserve-site.geojson` → при импорте выбрать «Запасные площадки»: добавляет точку возможной аварийной посадки, не командует БВС садиться.

В окне импорта сначала проверьте назначение, затем нажмите «Применить весь слой». Отмена ничего не меняет. Удаление запрета и пересчёт возвращают прежние условия.

Полная миссия — JSON другого формата: скачайте образец из карточки «Загрузить миссию» или текущий вход в «Данные миссии». KML/GeoJSON не заменяют парк, батареи, работы и временные окна.
