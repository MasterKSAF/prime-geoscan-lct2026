# Сервис планирования и распределения беспилотных авиационных работ

ЛЦТ 2026 · №5 · Геоскан · Прайм Planner · 2D · CPU · 17.09.2026

## Задача → результат {#task}

Распределить съёмку территории между БВС: **раньше закончить всё** или **меньше суммарно летать**. Получить рабочий веб, маршруты с расписанием, индивидуальные KML/GeoJSON и проверяемый отчёт. Комплект к 29.09 — не только макет.

## Что делаем {#mvp}

- **Мастер миссии:** работы → область/импорт → дата/окна → БВС/АКБ/базы → ограничения → проверка задания.
- **Расчёт:** пять типов работ, коптер/самолёт, две цели, качество, ветер/заряд, 4D-запреты, сближения, запас на посадку, повторные вылеты.
- **Рабочее место:** библиотека; YAML/JSON туда и обратно; два варианта → подтверждение → 2D-симуляция → экспорт. Карта, профиль высот и время согласованы. 3D отложен.

**Не выдумываем:** нормы для всех БВС, совместимость сенсоров, ресурс батарей. Паспортные числа, учебные допущения и неизвестное различаем. Правила времени суток зависят от работ; частичное выполнение — не успех.

**Стек:** React/TypeScript, Leaflet, Zod, геометрия, Node/Docker, node:test/Playwright. Локальный CPU; GPU/LLM не нужны. Текущий контейнер — 2 CPU/1 GiB; расширять после замеров. Карта не обязательна для расчёта; авторство сохраняется.

## Проверки и сдача {#evidence}

**E01–E16:** новый вход; безопасный импорт/обратный экспорт; окна/высоты/запреты; сближения; заряд и посадка вдоль пути; каждый профиль; повтор/батарея; подтверждение/stale; плеер = план; два чистых запуска. Эффективность — против допустимого baseline при равном качестве.

**Комплект:** код/архив, Docker, схемы/примеры, архитектура/алгоритм/API, руководство/ограничения, логи/трейсы/метрики, презентация и скринкаст. Цепочка: вход → версия/хеш → план → проверки → экспорт. Живой веб + резервное видео; публикация/GitHub после согласования.

## Границы и вопросы {#scope}

**Экспертам:** комплектации и качество LiDAR/геофизики; разнесение/высоты; обслуживание/батареи при отсутствующих данных. Пример входа и матрицу оценки ждём.

**Позже:** 3D, точная энергетика, погодный API, GCS и сложная зарядная инфраструктура. Симуляция — не телеметрия и не разрешение летать. План не равен готовому коду; первое место не гарантируется.
