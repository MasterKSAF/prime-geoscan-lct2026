```text
Сервис планирования и распределения беспилотных авиационных работ


        1. Контекст и актуальность задачи
    Беспилотные воздушные суда (БВС) всё шире применяются для мониторинга территорий,
инфраструктуры и промышленных объектов. Ключевым фактором ценности данных воздушной
съемки является скорость их получения. При использовании парка БВС возникает задача
автоматического распределения  полетов между несколькими аппаратами  с  учетом  их
характеристик, ограничений воздушного пространства и доступной инфраструктуры. Участникам
предлагается разработать интеллектуальный сервис планирования полетов БВС, повышающий
эффективность выполнения авиационных работ.


      2. Описание задачи
    Необходимо разработать программный сервис с веб-интерфейсом, рассчитывающий
оптимальные полетные задания для группы БВС.
    Входные данные:
     • координаты взлетно-посадочных пунктов (произвольные);
     • перечень доступных БВС;
     • область съемки;
     • тип съемки (RGB, мультиспектральная, ИК, LiDAR, геофизическая);
     • границы разрешенного воздушного пространства;
     • бесполетные зоны и резервные площадки посадки.
    Сервис должен формировать индивидуальные полетные задания (KML/GeoJSON) для
каждого БВС, исходя из их параметров полета, объема заряда и скорости, а также учитывая
скорость ветра. Индивидуальное полётное задание должно состоять из маршрута и ключевых
точек,  высоты,  скорости,  места  старта и  посадки,  последовательности  этапов  полёта.
Оптимизация должна поддерживать минимум два критерия: минимизация времени выполнения
работ и минимизация суммарного налета.


      3. Программно-аппаратные требования:
       3.1.  Решение должно работать в современном браузере на ПК.
      3.2.  Рекомендуемый  стек:  Python/Go/C#/Java,  JavaScript/TypeScript,  React/Vue,
GIS-библиотеки   (Leaflet/OpenLayers),  PostgreSQL/PostGIS  (по  желанию),  алгоритмы
оптимизации, ML/Data Science при необходимости.
```
