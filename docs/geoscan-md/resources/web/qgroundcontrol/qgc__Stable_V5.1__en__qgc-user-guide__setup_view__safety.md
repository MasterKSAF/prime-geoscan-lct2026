# Safety Setup

The *Safety Setup* page allows you to configure the most important failsafe settings (other failsafe settings can be set via the [parameters](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/setup_view/parameters.html) described in the failsafe documentation for each vehicle type).

For ArduPilot safety page information see: [Safety (ArduPilot)](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/setup_view/safety_ardupilot.html)
