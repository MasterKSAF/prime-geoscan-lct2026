# Analyze View

The *Analyze View* is accessed by selecting the *QGroundControl* application menu ("Q" icon in the top left corner) and then selecting the **Analyze Tools** button (from the *Select Tool* popup).

The view provides tools to:

- [Log Viewer](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/analyze_view/log_viewer.html) — Open and analyze `.bin` DataFlash logs and `.tlog` telemetry logs.
- [Download Logs](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/analyze_view/log_download.html) — List, download and clear logs on the vehicle.
- [GeoTag Images (PX4)](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/analyze_view/geotag_images.html) — Geotag survey mission images using the flight log (on a computer).
- [MAVLink Console (PX4)](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/analyze_view/mavlink_console.html) — Access the nsh shell running on the vehicle.
- [MAVLink Inspector](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/analyze_view/mavlink_inspector.html) — Display and chart received MAVLink messages/values.
