# Settings View

The *Settings View* is used to configure the settings for the *QGroundControl* application (rather than a specific vehicle). You do not have to have a vehicle connected to change these values.

You can switch between the various settings pages by clicking the buttons in the left-sidebar.

<a id="search"></a>

## Search

Use the **search bar** at the top of the settings sidebar to find any setting by name. As you type, matching settings are shown across all pages — click a result to jump directly to that setting. This is the fastest way to find a setting when you don't know which page it's on.

<a id="settings-pages"></a>

## Settings Pages

**[General](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/general.html)**
The main application configuration settings: display units, autoconnection devices, language, color scheme, and other core options.

**[Fly View](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/fly_view.html)**
Configure Fly View behavior: preflight checklist, guided mode, virtual joystick, and instrument panel options.

**[3D View](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/3d_view.html)**
Enable and configure the 3D map view.

**[Plan View](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/plan_view.html)**
Configure Plan View defaults: mission altitude, VTOL transition distance, and landing pattern options.

**[ADSB Server](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/adsb_server.html)**
Configure the ADS-B traffic tracking server connection for nearby aircraft display.

**[Comm Links](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/comm_links.html)**
Manually create communication links and configure auto-connect options.

**[Logging](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/troubleshooting/console_logging.html)**
Capture application logs for help with diagnosing problems.

**[Maps](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/maps.html)**
Map provider selection, offline tile management, API tokens, custom tile servers, and cache settings.

**[NTRIP / RTK](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/ntrip_rtk.html)**
Configure the built-in NTRIP client for streaming RTK correction data to the vehicle.

**[PX4 Log Transfer](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/px4_log_transfer.html)**
Configure PX4 log download and upload settings.

**[Remote ID](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/remote_id.html)**
Configure drone Remote ID settings including registration, region, and operator information.

**[Telemetry](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/telemetry.html)**
Settings associated with the MAVLink connection to a vehicle.

**[Video](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/video.html)**
Configure video source, stream URL, recording options, and decoder settings.

**[Help](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/settings_view/help.html)**
Links to QGroundControl user guide, forums, and support resources.
