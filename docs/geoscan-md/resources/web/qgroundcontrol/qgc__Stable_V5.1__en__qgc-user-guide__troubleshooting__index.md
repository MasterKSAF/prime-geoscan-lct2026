## Troubleshooting

Troubleshooting information is provided in two sections:

- [QGC Setup](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/troubleshooting/qgc_setup.html) - Troubleshooting *QGroundControl* installation and setup.
- [QGC Usage](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/troubleshooting/qgc_usage.html) - Troubleshooting problems when **using** *QGroundControl* to interact with a vehicle.

[Console Logging](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/troubleshooting/console_logging.html) explains how to capture *QGroundControl* application logs, which many of the troubleshooting procedures rely on.

If your questions are still unresolved, please check the [Support](https://docs.qgroundcontrol.com/Stable_V5.1/en/qgc-user-guide/support/support.html) page for more information on getting help.
