## How to get added to this list

If you or your company wants to be listed here please email [partners@ardupilot.org](mailto:partners%40ardupilot.org). To be added to this page we request the applicant has made a contribution to ArduPilot or a related project in some way. This includes code, documentation or helping people on the forums. The intention with this policy is to ensure that companies listed here will be active participants in the community.
