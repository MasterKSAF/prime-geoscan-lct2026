# SITL Parameters

ArduPilot SITL has many parameters with which one can simulate sensor failures, wind or wave influence, sensor imperfections, etc.

All SITL parameters are listed in each vehicle’s [Parameters](https://ardupilot.org/plane/docs/parameters.html#parameters-sim) page under “Simulation Parameters”.
