## Как парсить

- [SOURCE_INDEX.md](SOURCE_INDEX.md) — список всех 200 MD-копий с исходными URL.
- [reading-manifest.json](reading-manifest.json) — что прочитано, какие хеши относятся к этому проходу, ограничения охвата.
- [web-manifest.json](web-manifest.json) — MD-пути, размеры, хеши, количество таблиц/кода, результат проверки переноса текста.
- [download-manifest.json](download-manifest.json) — исходные HTML/PDF, URL, ошибки загрузки; скачивание не означает прочтение.
- [engineering-facts.json](engineering-facts.json) — компактные факты/решения для загрузки в контекст без полного корпуса.

Русские обзоры — осмысленная выжимка и перевод полезного. Полные открытые веб-руководства оставлены также **на английском**, чтобы не потерять названия полей, команд и оговорки. В HTML-таблицах внутри MD сохранены объединённые ячейки; серые неподдерживаемые параметры справочника MP дополнительно помечены текстом.

Статусы различать строго: `documented` — факт из документа; `inference` — наш вывод; `unknown` — данных недостаточно; `runtime_verified` — испытано. В этом исследовании новых фактов `runtime_verified` нет.

## Что не удалось закрыть полностью

Первоначальная недоступность главной страницы Planner и FAQ **снята чтением через Chrome**. Прочитаны описание, вкладка инструкций, все 10 FAQ Planner, журнал релизов и полезные связанные разделы — [точный состав дополнения](geoscan-site/README.md), [машинный реестр 50 страниц](geoscan-site/source-index.json). Отдельная ссылка на комплекс 401 Геофизика всё ещё привела к предупреждению сертификата и не включена в прочитанные. Открытый интеграционный API и актуальная автоматизация 801 не подтверждены.

Видео, все изображения/схемы, полные руководства каждой модели автопилота, RTKLIB, форумы, код всех репозиториев и реальные установки в этот статус не входят. Противоречия текстов и недостающие параметры не заменены догадками.
