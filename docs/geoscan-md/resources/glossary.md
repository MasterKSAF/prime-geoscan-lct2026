# Короткий словарь

Термины сведены из [прочитанных руководств](SOURCE_INDEX.md); пояснения адаптированы к нашей задаче.

| Термин | Простое объяснение |
| --- | --- |
| БВС / UAV | Сам беспилотный аппарат, а не весь комплект оборудования |
| БАС / UAS | Аппарат вместе с наземной станцией, связью и обеспечением |
| GCS / НСУ | Наземная станция управления; Geoscan Planner, QGC и Mission Planner относятся к этому классу |
| Полезная нагрузка | Камера, LiDAR, тепловизор, геофизический прибор и т. п. |
| RGB | Съёмка в видимом цветном диапазоне |
| Мультиспектр | Несколько отдельных спектральных каналов; не синоним тепловизора |
| ИК | Инфракрасный диапазон; требуемый тип ИК-съёмки и прибор необходимо уточнить |
| LiDAR | Лазерное измерение расстояний; результат и требования отличаются от обычных фотографий |
| GSD | Размер участка земли, приходящийся на пиксель; не равен точности геопривязки |
| Перекрытие | Часть соседних снимков, изображающая одну и ту же поверхность |
| Галс / transect | Рабочий проход съёмки, обычно прямолинейный |
| Транзит | Переход между площадкой и участком либо между участками |
| Makespan | Время завершения всей группы, то есть последней работы в расписании |
| Суммарный налёт | Сумма времени полёта аппаратов; трактовку метрики в ТЗ подтвердить у экспертов |
| Airspeed | Скорость относительно воздуха |
| Groundspeed | Скорость относительно земли; зависит от ветра |
| AGL | Высота над местной поверхностью земли |
| AMSL / ASL | Высота над средним уровнем моря; не над стартом |
| Relative altitude | Высота относительно заданной опорной точки, часто Home |
| Home | Домашняя точка автопилота; может изменяться при повторном старте |
| EKF origin | Начало координат оценивателя положения; не всегда совпадает с текущим Home |
| DEM | Цифровая модель высот; не гарантирует наличие всех зданий, деревьев и проводов |
| Геозона / fence | Зона разрешения или запрета; её отображение не доказывает автоматический обход |
| Rally point | Альтернативная точка возврата/ожидания/посадки; поведение зависит от типа аппарата и прошивки |
| RTL | Возврат; у разных аппаратов завершается по-разному, например посадкой или ожиданием |
| SoC | Оценка оставшегося заряда; сама по себе не даёт точного остатка минут полёта |
| PPK / RTK | Постобработка / обработка GNSS-поправок в реальном времени; не гарантия качества всей карты |
| SITL | Реальная программа автопилота работает с программно смоделированными датчиками/средой |
| Mock / анимация | Имитация состояния или показ расчётного плана; не испытание физики и прошивки |
| TLOG | Запись полученной наземной станцией телеметрии |
| DataFlash / ULog | Бортовые форматы журналов; набор данных зависит от стека и настройки |
| ACK | Подтверждение операции протокола, а не подтверждение успешного полёта |
| Round-trip | Экспорт → импорт/чтение → проверка, что смысл данных сохранился |
| Baseline | Фиксированный понятный способ решения, с которым сравнивают улучшенный алгоритм |
| Evidence bundle | Пакет входов, версий, результатов и логов, позволяющий проверить утверждения команды |

Числа и единицы должны быть явными в файлах. Для неизвестного параметра использовать `null` и статус `unknown`, а не придуманное значение по умолчанию.
