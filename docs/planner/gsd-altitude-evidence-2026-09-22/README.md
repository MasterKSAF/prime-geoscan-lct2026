## Повторение проверок

Из корня проекта в PowerShell 7, при установленных зависимостях Node.js:

```powershell
npm.cmd run test:planner
node --experimental-transform-types --experimental-test-isolation=none --test tests/acceptance/track5-readiness.test.ts
node --experimental-transform-types scripts/verify-altitude-http.ts http://127.0.0.1:3016 output/altitude-gsd/http-repeat
pwsh -NoLogo -NoProfile -File scripts/verify-browser-regression.ps1
npm.cmd run typecheck
npm.cmd run lint
```

HTTP и браузерные проверки требуют запущенного локального стенда. Браузерный скрипт использует Playwright CLI и Microsoft Edge, открывает отдельные тестовые сессии и сохраняет отчёты в `output/playwright/`. В скрипт общего прогона уже включены все пять групп, ожидается 82 проверки. Сценарии используют тестовые миссии; подтверждение загрузки проверяется явно.

## Что эти доказательства не подтверждают

Проверка высоты относится к принятой локальной поверхности. При неизвестном рельефе фактический AGL не доказан; `TERRAIN` остаётся неизвестным, `flightReady: false`. Это не разрешение на полёт, не сертификация и не доказательство качества реальных фотографий. Архив здесь — результат тестового экспорта из стенда, а не заново собранный официальный комплект сдачи. Презентация, доступы, commit и push не выполнялись.
