# Проверка обновлённого планировщика · 19.09.2026

Локальный стенд: <http://127.0.0.1:3016/planner>. Ядро 0.3.0, задание 2.0.
Это инженерная проверка конкретных сценариев, не гарантия отсутствия любых ошибок и не оценка жюри.

## Причина исчезновения карты

Включение рисования меняло `className` того же DOM-элемента, которым управлял Leaflet.
React стирал добавленные Leaflet классы, включая `leaflet-container`. До исправления это
воспроизведено в отдельном браузере: после нажатия оставалось `mission-map drawing`.

Теперь React управляет внешним контейнером, а Leaflet — отдельным внутренним узлом.
Рисование меняет атрибут внешнего контейнера. Отмена не заменяет исходную геометрию;
новый контур проверяется до применения. Масштаб учитывает все участки, базы и обходы маршрутов.
Без внешних тайлов остаются координатные слои, с сообщением об ошибке и повторной загрузкой.

## Что изменилось

- Координаты WGS84, номера вершин, отмена рисования через Esc, возврат к полному маршруту.
- Светлая, тёмная и системная темы с сохранением предпочтения.
- Пояснения `i`: мышь, клавиатура, нажатие; Escape закрывает подсказку, не окно под ней.
- Понятный автовыбор группы и предварительная совместимость; окончательная выполнимость — только после расчёта.
- До трёх найденных вариантов: время, суммарный налёт и баланс. Обязательные проверки качества и безопасности не ослабляются.
- Стрелка ветра с объяснением «откуда → куда». Это заданное постоянное поле, не живая карта погоды.
- Разделены примеры, сохранённые редактируемые задания и подтверждённые выполнения.
- Очередь, пауза, завершённые/отменённые снимки, восстановление карты и состояния, модельная доступность БВС/АКБ.
- Просмотр ползунком не перематывает сохранённую историю. Быстрый повторный запуск дожидается записи паузы.
- После аварийного закрытия оставшийся запуск требует явного восстановления; новая вкладка не перехватывает его автоматически.

Пошаговый сценарий: [рабочий цикл и UX-проверка](ux-guide-2026-09-19.md).

Первая попытка нового UX-теста остановилась на слишком ранней проверке удаления Leaflet-tooltip:
его штатная анимация длится около 200 мс. В тест добавлено ожидание удаления DOM-элементов.
Чистый повтор дал 118/118. Неудачные диагностические попытки сохранены отдельно, не выданы за успешные.

В тесте истории исправлены две ошибки проверки: HTML-ползунок округляет десятичный хвост числа
(допуск только для отображения — 10 нс; сравнение сохранённых значений точное), а Leaflet рисует
Canvas, не SVG. При нативных диалогах тестовый CLI мог раньше завершить вывод: итоговый отчёт
передан через объект тестовой страницы в Node, без изменения DOM, React или хранилищ приложения.
Надёжный полный прогон дал 32/32; три запроса расчёта вернули HTTP 200.

[журнал финальной сборки Docker](../../output/ux-verification-2026-09-19/final-docker-polish.log).
Запущенный образ — `sha256:5d9ae87724a65b9b9b85ea085c74231a688f60367a54597ab0b3b43ae1f9e23f`;
health — `healthy`, API — `status: ok`, `flightReady: false`.

После основных браузерных прогонов выполнены косметические правки подписи ветра,
переноса подсказок и расположения координат. Панель рисования закреплена выше координат,
а раскрывающийся список растёт вверх; длинная подсказка имеет ограниченную читаемую ширину.
Дополнительно добавлена седьмая регрессия
карты: свежий размер Leaflet перед fitBounds и сохранение центра при resize без
автоматической повторной подгонки. На раннем диагностическом скриншоте часть контура была
обрезана; повторный явный fit после завершения отрисовки вернул весь контур. Не установлено,
был ли причиной только ранний момент снимка или также прежнее поведение resize с `pan:false`.
Финальная проверка охватывает начальную подгонку после перезагрузки, повторную подгонку и resize.
