## Контроль перед сохранением формы

1. Открыть ссылки Google Drive в приватном окне без авторизации: документ читается, видео воспроизводится, ZIP скачивается. Отдельно проверить закрытый GitHub под учётной записью каждого приглашённого эксперта: принятые приглашения, просмотр и клонирование доступны. Анонимный просмотр GitHub для выбранной схемы не требуется.
2. Проверить, что все материалы относятся к одному срезу 0.4.0. Повторение ссылки на общую папку допустимо по переданной инструкции, но прямые ссылки на PDF и MP4 удобнее.
3. Заполнить пять полей, сохранить форму и подтверждение подачи **до 29.09.2026, 23:59 МСК**. После стоп-кода сданные материалы не менять.
