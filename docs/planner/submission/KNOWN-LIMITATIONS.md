# Ограничения рабочей версии

Planner **0.4.0**, 25 сентября 2026 года. Эти границы нужно учитывать при проверке и показе.

| Область | Что нельзя утверждать |
| --- | --- |
| Физические полёты | БВС не подключены. Опрос, демо-погода, телеметрия и образцы данных сенсоров — симуляция |
| Энергия | Публичные характеристики и расчётные профили не заменяют измерения с конкретной АКБ, нагрузкой и ветром |
| Камеры | Нужна установленная совместимая камера с достаточными параметрами. Неполные 801/Riebo и ZV-E10 без объектива не получают выдуманную GSD/полосу. В демо интервал кадров и выдержка — модельные допущения |
| Совместная съёмка | Одна работа использует одну оптическую сетку; разделение — между эквивалентными камерами. Смешанная сетка разных камер в одной работе не заявляется |
| Оптимальность | Ограниченный CPU-поиск не доказывает лучший из всех возможных планов; `not_found` не доказывает невозможность |
| Три варианта | Найденные стратегии могут совпасть; стенд не обязан выдумывать третий маршрут |
| Покрытие | Допуск модели — от 99%; в отчёте показано фактическое значение. 100% выполненных проходов не равно 100% территории |
| Рельеф | TIFF/DEM не поддержаны; плоская/неизвестная поверхность не даёт достоверную реальную высоту над землёй |
| KML препятствий | Консервативный горизонтальный обход. Высота исходника не превращает его автоматически в проверенную объёмную модель |
| Воздушное пространство | Карта и пользовательский контур не являются разрешением; актуальные внешние ограничения автоматически не гарантируются |
| Высотные зоны KML | FL пересчитывается по объявленной модели атмосферы, не по измеренному QNH. AMSL/AGL требуют заданной плоской поверхности. Из 341 зоны 335 диапазонов разобраны; шесть неизвестных не стали свободным пространством. Расписание временных зон в исходнике отсутствует |
| Нормативы | Реализованы выбранные положения и требования трека, не полная сертификация по всем ГОСТам и правилам |
| Аварии | Защитный возврат может оказаться недопустимым. При блокировке нельзя объявлять благополучную посадку |
| Внешние БВС | Произвольное стороннее воздушное движение и реальные аппаратные отказы не наблюдаются |
| Формат маршрутов | KML/GeoJSON — описательные полётные задания для проверки, не подтверждённые команды конкретному автопилоту |
| Погода | Демо использует модельный снимок. Прогнозный адаптер не даёт измеренного 4D-поля ветра по всему маршруту |
| Сессия | Перезагрузка очищает демонстрационные миссии/историю; нужные данные надо заранее скачать |
| Публичный сервис | Локальный стенд не имеет подтверждённого промышленного контура авторизации, эксплуатации и нагрузочной защиты |

## Ограничения входа

Основная миссия — до 200 КиБ; расширенный запрос со слоями — до 12 МиБ. Есть лимиты геометрии и вычислительного бюджета. При превышении должен возвращаться отказ, а не успешный расчёт по незаметно урезанным данным.

Схема допускает до 20 БВС, 8 записей работ/участков, 40 баз, 20 явно заданных ограничений; полные внешние каталоги учитываются отдельно. Окно — не более семи суток. Результат зависит от конкретной геометрии и допустимого бюджета поиска, а не только от площади.

В сессии: 50 карточек / 80 МиБ, три активных запуска, 20 записей истории. Удаление одной карточки не должно удалять соседние; ограничения не обходятся скрытой очисткой.

## Что ещё требуется перед сдачей

Материалы и свежие проверки 0.4.0 подготовлены. Остаются выбор окончательного среза владельцем, разрешённые commit/push, проверка чистого клона, внешних ссылок и сохранение формы. Прототип в форме — видеопрезентация, отдельный сайт не разворачивается.
