## Перед сохранением формы сдачи

| Действие | Кто/когда |
| --- | --- |
| Просмотреть комплект и зафиксировать срез сдачи | Владелец; исходный код Planner 0.4.0 хранится в закрытом GitHub. Записать commit и SHA-256 соответствующего ZIP |
| Проверить исходники из чистого клона | Проверка ZIP не заменяет проверку клона; фактически выполненные проверки записываются отдельно, без автоматического зачёта повторного запуска Docker |
| Предоставить гостевой доступ к GitHub каждому эксперту | Репозиторий остаётся PRIVATE. Получить логины, проверить принятие приглашений, просмотр и клонирование под учётными записями экспертов до сдачи; одной закрытой ссылки недостаточно |
| Убедиться в полной загрузке актуального комплекта в Google Drive | PDF/MP4 размещены, доступ по ссылке включён; после обновления ZIP проверить совпадение скачанного архива и контрольной суммы. Ссылки — в FORM-FIELDS.md |
