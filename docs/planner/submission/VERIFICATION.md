## Как обеспечена чистота

Из выбранных файлов Git index создан новый каталог через `git checkout-index --all --prefix=...`. В нём нет незафиксированных сторонних файлов, node_modules и локальных секретов исходной рабочей папки. Docker выполняет `npm ci`, проверку типов, тесты и сборку. После сборки контейнер запущен только на loopback:3018, 2 CPU, 1 ГиБ, без capabilities, с no-new-privileges.

Образ проверки: `prime-planner:expert-20260922`; digest `sha256:aa30a7496a2d0a971155d3179fb55eb6440130eb053756922a7b28942332698c`. Это локальный образ, он не опубликован в registry. В Git находятся рецепт и зависимости; пересборка может давать иной digest при тех же исходниках.

Файлы кода для benchmark перечислены с SHA-256 в его report.json. Общий [реестр](evidence/artifact-manifest.json) связывает код, документацию, слайды и доказательства. Реестр не хеширует сам себя. Команда `node scripts/verify-submission.mjs` работает и из распакованного архива, без Git и npm-пакетов; она проверяет целостность и локальные ссылки актуальной документации, а не логику полёта.

## Что измерил benchmark

Среда: Node 24.14.1, Windows x64, AMD Ryzen 5 7430U, 12 логических CPU; один процесс Node, без GPU и сетевых запросов. Полные условия записаны в отчёте. CPU/время наблюдаются при фоновой нагрузке и не являются SLA.

Наш поиск нашёл полный допустимый модельный план для **11 из 21** задач, обе базовые стратегии — для **10 из 21**. На 10 сопоставимых задачах × 3 повтора:

| Медианное сокращение | Против последовательного baseline | Против параллельного baseline |
|---|---:|---:|
| Времени завершения | 37,34% | 0,95% |
| Общего налёта | 3,28% | 0,58% |

Остальные исходы сохранены: на каждый критерий 33 feasible_model, 15 partial, 9 not_found, 6 unsupported (включая повторы). Это не 63 независимые миссии и не доказательство глобальной оптимальности. Медиана времени нашего поиска 60,50 мс, p95 185,61 мс. Простые baseline считаются быстрее; выгода относится к полученному плану, а не к скорости вычислений.

Полная папка benchmark включает входы, кандидатов всех стратегий и evidence положительных результатов. Не выбран только удачный поднабор. Независимая команда повторяет арифметику и модельные проверки, но использует общие модули геометрии.

## Ограничения выводов и повторение

Хеши подтверждают неизменность, а не достоверность измерения. Уязвимости не исчерпываются npm audit; в том числе dev-зависимости и публичный security-аудит этой цифрой не покрываются. Лицензии проинвентаризированы, но юридическая сертификация совместимости не заявлена.

Тесты не заменяют реальную телеметрию, DEM, калибровку энергии и съёмки, разрешение на полёт и приёмку автопилотом. [Известные ограничения](KNOWN-LIMITATIONS.md) остаются действующими.

Команды повторения: [чек-лист эксперта](REVIEW-CHECKLIST.md). Доступ к закрытому GitHub и фактическая загрузка на конкурсную площадку — отдельные действия владельца.
