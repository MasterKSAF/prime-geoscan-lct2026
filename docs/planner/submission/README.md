## Что сдаётся

Исходный код и Docker-демо лежат в корне репозитория. Презентация и вся текущая сопровождающая документация находятся в этой папке. Входные демо: [каталог](../../../public/planner/scenarios). Схема и API: [контракт](../contracts/mission-v2.schema.json), [API](../api-v2.md). Оригинальные требования: [ТЗ](../../references/track5-geoscan-original.pdf), [его Markdown](../../geoscan-md/geoscan-track5-tz.md).

Пакет соответствует структуре выдачи §7.2 ТЗ: код, исполняемое демо, презентация, документация и инструкция запуска. Это состав поставки, а не утверждение о прохождении всех критериев жюри. Существенные модельные ограничения перечислены отдельно.

## Актуальность и доступ

Эта папка имеет приоритет над историческими инструкциями 17–21 сентября для текущей поставки. Машинный benchmark содержит как успешные, так и неполные, ненайденные и неподдержанные исходы. Их нельзя удалять ради процентов.

GitHub остаётся закрытым. По решению владельца приглашения экспертам отложены до получения логинов. Наличие файлов в репозитории не означает, что эксперт уже имеет доступ или что решение загружено на конкурсную площадку.

Архив создаётся из зафиксированного коммита командой `git archive`, без рабочей библиотеки браузера, токенов, установщиков и материалов других треков. Архив не вкладывается сам в себя и не требуется для запуска из GitHub.
