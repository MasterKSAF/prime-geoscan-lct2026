## Что входит в комплект

Код с README и Docker для локального запуска, документация, актуальная презентация, видеопрезентация и выгрузки демонстрационных миссий. Отдельного публичного сайта не будет: в поле «Прототип» указываем видео. ZIP одной миссии — доказательства её расчёта/запуска, а не замена всему комплекту проекта. [Ссылки для пяти полей формы](FORM-FIELDS.md).

GitHub остаётся закрытым. До сдачи каждому назначенному эксперту нужно предоставить гостевой доступ для проверки и проверить принятие приглашения, просмотр и клонирование под его учётной записью. Ссылка без такого доступа не считается доступным материалом. Google Drive проверяется отдельно — без авторизации.
