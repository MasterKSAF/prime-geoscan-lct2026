# Короткая ручная проверка

Planner **0.4.0**. Заполняется человеком после фактического прохода. Автотесты не ставят галочки за эксперта. Полные предусловия, критерии трёх сценариев и всех классов кнопок — в [методике приёмки](ACCEPTANCE-PROCEDURE.md).

Перед началом скачайте важные данные. Начните чистую сессию; при проверке не обновляйте страницу без сохранения.

Дата и проверяющий: __________. Версия ядра / commit или SHA-256 комплекта: __________. ОС / браузер: __________. Каталог доказательств: __________. Пустое поле означает «не заполнено», а не положительное заключение.

| Проверено | Действие | Ожидаемый результат |
| --- | --- | --- |
| [ ] | Открыть «Миссии» | Три примера и карточка загрузки, нет старых запусков |
| [ ] | Демо 1 → редактор → рассчитать | Допустимые варианты, понятные метрики и марки БВС |
| [ ] | Подтвердить и выполнить Демо 1 | Движение на карте, журнал выбранной миссии, остаток батареи |
| [ ] | Открыть отчёт | Отдельно статус, выполнение проходов и покрытие территории |
| [ ] | Скачать маршруты и доказательства | ZIP открывается; для назначенных БВС есть KML/GeoJSON |
| [ ] | Рассчитать и выполнить Демо 2 | Учитываются слои экспертов; проходят проверки маршрутов и разнесения |
| [ ] | Рассчитать исходное Демо 3 | Запуск заблокирован, причины видны, скачивается диагностический ZIP |
| [ ] | Скачать миссию, изменить ID и загрузить копию | Новая карточка рядом, исходная миссия не заменена |
| [ ] | Загрузить повторный ID или повреждённый файл | Явный выбор/ошибка; соседние карточки не потеряны |
| [ ] | В копии создать/перенести базу; удалить с переназначением | Координаты и назначения согласованы, заряд не обнулён |
| [ ] | Очистить/восстановить границу; отменить правку вершины | Без границы расчёт заблокирован; отмена возвращает геометрию |
| [ ] | Добавить и удалить запрет | Меняется ограничение, а не участок съёмки; нужен новый расчёт |
| [ ] | Вернуться из отчёта; проверить светлую/тёмную темы | Понятная навигация, карта и действия не перекрыты |
| [ ] | Повторно проверить свежий ZIP командой | Ожидаемый статус из [инструкции](EXPERT-FILES.md) |

Для Демо 2 допустимо **100% проходов при 99,501122% территории** в проверенном исходном срезе. Не исправляйте цифру в отчёте вручную.

Если нашли проблему, сохраните: полный JSON миссии, ZIP доказательств, архив/JSON события при аварии, скриншот, последовательность действий и ответ `/api/planner/health`. Это позволяет отличить конфликт расчёта от ошибки интерфейса.
