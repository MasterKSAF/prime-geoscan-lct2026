# Требования и доказательства

Planner **0.4.0**. Основание — [ТЗ](../../geoscan-md/geoscan-track5-tz.md), [материалы 22 сентября](../expert-materials/2026-09-22/README.md), [23 сентября](../expert-materials/2026-09-23/README.md), сохранённые ответы экспертов.

Числовая матрица жюри не предоставлена. Эта таблица помогает проверить реализацию, но не присваивает баллы.

## Требования ТЗ

| Основание | Реализация | Как проверить |
| --- | --- | --- |
| §2 — входные данные | Работы, участки, парк, точки старта/посадки, допустимая область, запреты, запасные площадки | Редактор → Данные миссии → Объекты карты; JSON; [тесты объектов](../../../tests/mission-session-objects.test.ts) |
| §2 — пять видов работ | RGB/MS/IR/LiDAR/геофизика, совместимость установленной нагрузки | [Полный проверочный путь](../../../tests/mission-expert-pipeline.test.ts); Демо 1/2 демонстрируют RGB/MS |
| §2 — параметры БВС, энергия, ветер | Модель движения, текущая батарея, резерв, ограничения погоды | [Батарея](../../../tests/mission-current-battery.test.ts), [условия](../../../tests/mission-environment.test.ts); проверки плана |
| §2 — два критерия | Время последней посадки и суммарный налёт на одном входе | Демо 1/2; [сравнение](../../../tests/mission-comparison.test.ts), [поиск расписаний](../../../tests/mission-schedule-search.test.ts) |
| §2 — выходные файлы | Индивидуальные KML/GeoJSON с этапами, временем, скоростью и высотой | Отчёт → Скачать маршруты; `data/routes/` в ZIP; [экспорт](../../../tests/mission-export.test.ts) |
| §3 — веб на ПК | Пять основных разделов, карта, современный браузер | [Свежий браузерный протокол](VERIFICATION.md), [методика](ACCEPTANCE-PROCEDURE.md) и [ручной лист](MANUAL-REVIEW.md) |
| §4 — демонстрация | Визуальные маршруты, метрики, выбор плана, экспорт | [Три сценария](DEMO-SCRIPT.md); два допустимых примера и один отказ |
| §5 — документация | Архитектура, алгоритм, запуск, API, руководство, ограничения и формуляр программы | [Индекс](README.md), [технический обзор](SOLUTION-PASSPORT.md), [формуляр ЕСПД](FORMULAR-GOST.md), [методика приёмки](ACCEPTANCE-PROCEDURE.md), [API](../api-v2.md) |
| §6 — материалы БВС | Профили Геоскан 201, 801, Gemini | [Обоснование состава](../fleet-scope-0.3.8.md); самолётный 201 не подменён мультиротором |
| §7 — комплект сдачи | Код, Docker, входы, документация, рабочие выгрузки | Материалы готовы; фиксация, чистый клон и доступ — в [списке подготовки](READINESS.md) |
| §8 — качество/эффективность | Автотесты, ограниченный CPU-поиск, явные отказы и протоколы | [Результаты](VERIFICATION.md); свежий benchmark: 21 случай, 63 запуска, включая ожидаемые отказы |

## Уточнения экспертов

| Уточнение | Реализация и проверка | Граница |
| --- | --- | --- |
| GSD и высота | Расчёт камеры, ограничение высоты; [тесты](../../../tests/mission-altitude-gsd.test.ts) | Не оценка настоящего кадра |
| Предел 150 м | Все фазы строго ниже предела над принятой поверхностью; автоматический потолок 149 м | Без DEM реальная AGL не подтверждается |
| Столкновения и коридоры | Непрерывная сепарация, наземная занятость, допустимая граница | [Непрерывные проверки](../../../tests/mission-continuous-safety.test.ts), [наземное разнесение](../../../tests/mission-ground-separation.test.ts); не реальные внешние БВС |
| Экспертные KML | Полный источник, хеши, применение зон/препятствий, экспорт | [Импорт препятствий](../../../tests/obstacle-layer.test.ts), [каталоги](../../../tests/mission-catalog.test.ts); обход KML-препятствий горизонтальный |
| Высоты и время запретов | FL/AGL/AMSL, смешанные границы, временные зоны, взлёт/посадка и возврат, нормализация в ZIP | [Тесты высотных зон](../../../tests/mission-airspace-altitudes.test.ts), [пообъектный аудит](../airspace-source-audit-2026-09-24.json); ISA и плоская поверхность — объявленная модель, не измерения |
| Лимит группы и срок | `maxVehicles` — разные БВС за всю миссию; срок обязателен; минимум налёта среди найденных допустимых | [Ресурсы](../../../tests/mission-resources.test.ts); не гарантированный глобальный оптимум |
| Наработка и батареи | Счётчик аппарата отдельно от текущей батареи, повторный вылет при достаточном остатке | Модельные данные не являются физическими измерениями |

## Дополнительные возможности решения

| Возможность | Где видна | Доказательство |
| --- | --- | --- |
| Понятное объяснение отказа и действия | Демо 3 → Все проверки | [Гипотезы исправления](../../../tests/mission-demo-repairs.test.ts) |
| Свои миссии в общей колоде | Загрузка рядом с тремя примерами | Датированный [протокол карточек/объектов](../map-and-missions-2026-09-24-verification.json), завершённая миссия с произвольным ID |
| Общий парк и безопасные базы | Парк, Объекты карты | Заряд сохраняется; перенос с незавершёнными запусками блокируется |
| Повторная проверка ZIP | Отчёт → Доказательства ZIP | [Инструкция](EXPERT-FILES.md), состав и даты проверенных архивов в [протоколах](VERIFICATION.md) |
| Отдельный защитный возврат | Нештатное событие и проверки возврата | [Возврат](../../../tests/mission-recovery-dispatch.test.ts), архив события |
| Запись модели в MP4 | Выполнение | Видео — наглядность, не замена числовых доказательств |

Не смешивать «реализовано в модели», «проверено в данном прогоне» и «готово к финальной сдаче». [Ограничения](KNOWN-LIMITATIONS.md).
