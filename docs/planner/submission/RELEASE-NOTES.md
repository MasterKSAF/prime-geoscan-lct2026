# Изменения комплекта r3

Основание: материалы экспертов от 22.09.2026 и текущая реализация стенда.

- Новое Демо 2 использует оригинальный KML с 3 201 препятствием. Полный источник переносится вместе с миссией.
- Добавлены инструкция слоя, правила высот, технические бюджеты и запрет молчаливого пропуска объектов.
- Приложен скачанный из браузера ZIP / BagIt 1.0 завершённой миссии, отдельный CLI-пересчёт и проверка стандартной библиотекой Python.
- Пересчитан весь benchmark 21 × 3. Заменены прежние тестовые логи и браузерные снимки, без переноса старого числа 50 проверок на новый интерфейс.
- Обновлены презентация, речь, паспорт, матрица требований, README и инструкция. Один основной PPTX, PDF и HTML одной редакции.
- 12 слайдов экспортированы PowerPoint 16.0 и просмотрены по отдельности. После исправления подписи на слайде 8 геометрический валидатор не нашёл пересечений/выходов текста.
- Из актуального комплекта убраны прежние benchmark/API/browser-протоколы, скриншоты и дублирующая corrected-презентация. Для восстановления сохранена локальная копия `output/submission-backups/pre-obstacles-20260922` вне поставки, также доступна история Git.
- Исходники экспертов, письменное ТЗ и регрессионные примеры сохранены. Материалы других треков и установщики в коммит не включаются.

Известный 503 после отклонения большого HTTP-запроса сохранён в журнале и ограничениях. Модель не объявляется аппаратно готовой. Доступ экспертов и отправка на конкурс не выполнены автоматически.
