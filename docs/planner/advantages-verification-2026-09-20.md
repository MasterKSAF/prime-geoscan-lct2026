## Что именно доказали сценарии

**Устойчивость.** Для `automatic-tradeoff` усиление ветра на 2 м/с и снижение заряда на 10 процентных пунктов выявили нарушения. Поворот ветра на 45° и задержка на 5 минут прошли в объявленной модели. Повторная проверка подтверждает эти же результаты, а не рисует общий зелёный статус. Пробы независимы: одновременное сочетание четырёх изменений не проверялось. Это не вероятность успешного полёта.

**Остаток.** В примере с внутренним отверстием после полностью завершённого первого прохода и прерывания следующего создан новый черновик. Частичный проход не засчитан, отверстие сохранено, исходный срок не продлён. Исходный участок — 148 500 м²; зачтено примерно 28 437,5 м², осталось 120 062,5 м². [Скачанное обоснование](../../output/playwright/mission-analysis/remaining-work.json) содержит журнал-привязку, хеши входа/плана/парка/черновика и фактическую численную погрешность геометрии. На принятой сетке 1 мкм допускается суммарно не более 0,1 м², без потери частей и отверстий.

Браузерный тест заканчивается открытием нового черновика. Отдельный интеграционный тест `mission-remaining-work.test.ts` проверяет продолжение целиком: реальное хранилище операций → защитная посадка → отдельное сообщение о готовности с тем же зарядом, без замены батареи → остаток → новый допустимый расчёт. Это **не автоматическое перепланирование в воздухе** и не подтверждение качества реальных снимков.

**Эффективность.** В фиксированном сравнении полные допустимые планы обеих сторон получены для 7 из 15 входов. Остальные 8 не скрыты и не включены в процент экономии за невыполненную работу. На сопоставимых парах медианное сокращение времени завершения — 5,82%, медианное сокращение налёта — 0%. Это ограниченный синтетический набор, не независимое сравнение с коммерческим ПО. Времена CPU, хеши и полный протокол — в отдельном актуализируемом отчёте benchmark.

## Воспроизведение

Из корня проекта после установки зависимостей; Docker-сборка сама выполняет типизацию и основную регрессию:

```powershell
docker compose -p lct -f compose.planner.yaml up --build -d
node --experimental-transform-types --experimental-test-isolation=none --test tests/acceptance/track5-readiness.test.ts
node --experimental-transform-types scripts/verify-collision-safety.ts http://127.0.0.1:3016 output/advantages-safety
npm run verify:evidence -- output/playwright/mission-analysis/counterfactual.evidence.json output/playwright/mission-analysis/counterfactual.verification.json
node --experimental-transform-types scripts/verify-mission-robustness.ts output/playwright/mission-analysis/robustness.json output/playwright/mission-analysis/robustness.recheck-new.json
npm run benchmark:missions -- output/mission-benchmark 3
npm run verify:benchmark -- output/mission-benchmark/report.json
```

Выходной путь стресс-проверки должен быть **новым**: инструмент не перезаписывает имеющиеся файлы. Браузерные пакеты получают кнопками интерфейса; сценарии автоматизации сохранены в `scripts/verify-mission-analysis-browser.js`, `scripts/verify-mission-analysis-negative-browser.js`, `scripts/verify-mission-remaining-browser.js`. Они исполняются Playwright CLI через `run-code --filename`, не являются обычными Node-скриптами. Для теста возврата использовать отдельный чистый профиль; пользовательские данные не очищать.

## Оставшиеся границы

- Полёты Геоскан 201 **не поддержаны**: есть паспортные ограничения, защита от подмены коптерным профилем и геометрические заготовки, но нет сквозной самолётной модели.
- Нет полётной калибровки энергии, реальной телеметрии и подтверждённого DEM. Погодный прогноз — снимок, не измеренное поле ветра на высотах БВС.
- Поиск ограничен временем. Не найденный план не доказывает невозможность. Сетка изменённого ветра и задачи 10/100 км² выявляют незакрытые случаи.
- Геометрическое покрытие не доказывает резкость, фактическое получение кадров или качество LiDAR. `unknown` сохраняются.
- Выдаваемые KML/GeoJSON не объявлены проверенными командами реального автопилота. Проверки не заменяют разрешения полётов и не подтверждают официальный балл или первое место.
