1. Общий поиск: порядок работ, ограниченная группа, сдвиги вылетов, прямые переходы и уплотнение расписания; одинаково для JSON и редактора. Сохранить все защитные проверки. Не объявлять ограниченный поиск глобальным оптимумом.
2. Проверка 401/501: в письменном ТЗ перечислены 201, 801, Gemini. 401/501 встречаются в резюме ответа о ТО; обязательного добавления в парк источник не устанавливает. См. [состав парка](fleet-scope-0.3.8.md).
3. Комплект эксперта: индивидуальные KML/GeoJSON, исходный вход, план, проверки, журналы, источники и инструкция повторного запуска. См. [проверка файлов](submission/EXPERT-FILES.md).
4. Карта: отдельная кадровая интерполяция подтверждённого модельного времени, без срезания углов; стабильные статические слои вместо перестройки на каждом тике.
5. Загрузка: компактный паспорт, без полного JSON и рекламных примечаний; скачивание JSON и HTML, подтверждение отдельно.
6. Выполнение: единая группа действий; ускорение рядом с запуском; аппараты и расписание только на вкладке БВС; отчёт отдельной кнопкой; MP4 неактивен, пока запись недоступна.

## Архитектура поиска

Геометрия и параметры работ кешируются только внутри одного неизменяемого расчётного снимка. Перебираются ограниченные перестановки работ, варианты групп и упаковки полос. При точном поиске старта проверяется секундная сетка, вместо безусловного переноса вылета за полную посадку другого аппарата. После соединения участков выполняется ограниченное уплотнение расписания с полной проверкой каждого принятого результата.

Критерии сравниваются лексикографически: основной показатель, затем второй, затем число БВС и длина. Сохранённые проверки упорядочены по исходной миссии независимо от порядка поиска. Новое событие SCHEDULE_COMPACTION включено в формат диагностической трассы.

Границы: это ограниченный детерминированный набор стратегий с временным бюджетом, не CP-SAT и не доказательство оптимума произвольной непрерывной траектории. Непрерывная проверка безопасности не заменена секундной выборкой: секундная сетка относится только к поиску старта.
