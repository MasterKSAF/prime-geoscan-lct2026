# Сохранённые первоисточники

Здесь находятся неизменённые копии документов, использованных при подготовке модели Planner. Состав и SHA-256 — в [manifest.json](manifest.json). Копии перенесены из временных исследовательских каталогов 25 сентября 2026 года; это дата упаковки, а не новая редакция документа.

## Нормативные материалы

- [ФАП № 138, сохранённая редакция 31.07.2025](standards/fap138-revision-2025-07-31.pdf).
- [ГОСТ Р 59328–2021](standards/gost-r-59328-2021.pdf) — условия аэрофотосъёмки.
- [ГОСТ Р 59562–2021](standards/gost-r-59562-2021.pdf) — контекст аэрофототопографических работ.
- [ГОСТ Р 70078–2022](standards/gost-r-70078-2022.pdf) — программно-аппаратный комплекс планирования.

Применённые положения и пределы их использования разобраны в [справке по нормам](../standards-profiles-and-missions.md). Наличие PDF не означает соответствие решения каждому пункту документа и не заменяет проверку действующих региональных ограничений или разрешение на полёт.

Документы принадлежат их правообладателям; эта папка сохраняет происхождение использованных сведений для проверки. Исходные исследовательские копии не удалены. Поле `originalLocalPath` в манифесте — история происхождения, не обязательный путь для запуска и не ссылка на файл комплекта.
