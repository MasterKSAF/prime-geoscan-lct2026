Текущая модель использует текущую батарею каждого БВС, повторные вылеты и подтверждаемое обновление состояния. Старые документы 0.2/0.3 и датированные исследования сохранены как история: описания зарядников, склада батарей, прежней навигации и отсутствующего прогноза в них не являются спецификацией текущей версии.

Четыре раздела интерфейса: **Миссии, Редактор, Выполнение, Парк БВС**. Отчёт открывается из выбранной миссии. Это проверяемая инженерная модель, не автопилот и не подтверждение реального полёта.
