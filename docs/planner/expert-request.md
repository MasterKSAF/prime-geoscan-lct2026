# Запрос экспертам Геоскана: данные для рабочей модели

Статус: подготовлен по просьбе команды, **не отправлен**. Сейчас реальных полётных логов у команды нет.

Добрый день! Мы делаем сервис распределения авиационных работ между БВС по задаче №5. Хотим проверять не только геометрию, но и выполнимость задания по заряду и параметрам съёмки. Помогите, пожалуйста, уточнить четыре пункта.

1. **Можете предоставить обезличенные логи нескольких типовых полётов Геоскан 201, 801 и Gemini?** Нужны временные метки, модель и версия конфигурации, тип АКБ и нагрузка, начальный/конечный заряд, ток и напряжение при наличии, координаты/высоты/скорости; отдельно — известные условия ветра и температуры. Если часть каналов недоступна, достаточно имеющихся с описанием единиц и источника времени.

2. **Какая модель оценки ресурса считается достаточной на хакатоне: настраиваемое время полёта с резервом или расход энергии по фазам?** Есть ли рекомендованные рабочие бюджеты/резервы и данные по влиянию конкретной нагрузки, включая питание камеры от собственной либо бортовой батареи?

3. **Какие конкретные связки БВС + сенсор будут проверяться для пяти типов работ?** Какие параметры качества вы зададите: GSD/перекрытия/минимальный интервал кадров либо ширина полосы, плотность/шаг измерений и высота сенсора?

4. **Какая схема KML/GeoJSON и версия целевого ПО являются эталонными для приёмки?** Нужен ли фактический импорт и автоматическое выполнение задания на 801 или достаточно маршрута с атрибутами высоты, скорости, старта/посадки и последовательности фаз?

Просим по возможности небольшой пример входного сценария и корректного результата. Пока все неподтверждённые параметры обозначаем как допущения, а не характеристики производителя.

## Как зафиксировать ответ

Дата, имя эксперта, точная комплектация/версия, источник, разрешение на использование/публикацию данных. Не выкладывать логи с координатами заказчика в открытый репозиторий без разрешения. Уточнения рельефа, повторных вылетов и критерия налёта остаются в общем [списке вопросов](../geoscan-md/resources/critical-expert-questions.md).
