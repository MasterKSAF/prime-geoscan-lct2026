## Очередь оставшейся работы

### P1 · до заявления о готовности MVP

1. **Расширить приёмку и подготовить release.** Сборка, 74 теста, typecheck, 10 API-проверок, 24 браузерные проверки, модельные доказательства, 21 контейнерный хеш и повтор в двух свежих контейнерах уже проверены. Для release ещё нужны два независимых чистых build/run, полный офлайн-сценарий после подготовки и оставшиеся проверки E12. Свежий контейнер из того же образа не равен независимой чистой сборке.
2. **Проверить обязательный охват с экспертами.** 201, реальные сенсорные комплектации, формат входа/матрица оценки и допустимые упрощения. Пока письменного согласования нет, отсутствие 201/DEM не превращать в «ТЗ выполнено».
3. **Усилить расчёт крупных миссий.** Текущий вход 100 км² не решён. Проверить разбиение длинных рабочих проходов, ресурсы/базы и назначение; после изменений заново доказать полноту покрытия, ресурс и разнесение. Один быстрый отказ не является benchmark успешного планирования.
4. **Закрыть независимые эталоны.** Три малых ручных/точных случая, негативные профили всех видов работ, края фотоотпечатков, сценарии альтернативного ухода. Отдельно проверить, что общая геометрия не скрывает общую ошибку решателя и валидатора.
5. **Определить высотный контур.** До реального DEM — ясно ограничить модель; затем добавить датум, NoData, интерполяцию и проверку высоты датчика/БВС. Нельзя подставлять нулевой рельеф вместо неизвестного без явного согласия.
6. **Заморозить и очистить сдаваемый комплект.** Зафиксировать release ID и исходники; проверить лицензии/атрибуцию и отсутствие секретов, чужих треков/установщиков/частных записей; выполнить два чистых запуска, затем слайды и скринкаст из той же версии. Публикация/репозиторий — отдельное согласованное действие.

### P2 · после обязательной приёмки

Поиск высоты по предпочтению, улучшение эвристики по эталонам, дополнительные подложки/офлайн-данные с разрешённой лицензией, общая серверная библиотека при необходимости. 3D, погодный API и реальное управление БВС не входят в текущий готовый объём.
