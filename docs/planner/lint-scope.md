# Область автоматической проверки кода

## Текущая проверка · 24 сентября 2026

Полный `npm run lint` имеет отдельные замечания в старых и посторонних скриптах; его чистота не заявляется. Для основной области планировщика:

```powershell
npx oxlint app/planner components/planner lib/planner lib/server hooks/use-mission-operations.ts hooks/use-mission-recordings.ts hooks/use-view-history.ts tests
```

Новые служебные скрипты проверяются отдельно. Проверка стиля не заменяет типы, тесты и браузерный прогон. [Действующие команды](submission/REVIEW-CHECKLIST.md).

## История настройки области проверки

`npm run lint` проверяет исходники продукта: `app`, `components`, `hooks`, `lib`, `tests`, `scripts` и корневые конфигурации сборки. Проверка типов включена в oxlint; дополнительно выполняется `npm run typecheck`.

Не входят чужой трек `submission/bez-nomera`, исследовательские `experiments/vehicle/training`, документы, зависимости и генерируемые результаты. Их вложенная конфигурация раньше ломала запуск lint до проверки нашего кода. Эти чужие файлы не изменялись.

Точечные исключения, не маскирующие ошибки приложения:

- Файлы callback для Playwright CLI — намеренно самостоятельное выражение `async page => { ... }`, которое исполняет CLI. Для них отключено только `no-unused-expressions`, остальные правила сохраняются.
- `components/ui` — библиотечные примитивы с ARIA-ролями и слотовой композицией. Отключена только рекомендация `prefer-tag-over-role`: замена универсального контейнера на fieldset/menu меняет семантику потребителей. Правила доступности остаются включёнными.
- Примитив Label получает `htmlFor` либо вложенный input через props; локальное исключение отражает этот контракт.
- Клик на декоративном дополнении InputGroup лишь переводит фокус на уже доступное с клавиатуры поле; не создаём лишнюю кнопку/таб-остановку ради формального lint.

Ошибки React исправлены в коде: обновление ref перенесено в effect, порядок объявления обработчика исправлен, подписки media query/карусели используют useSyncExternalStore с cleanup. React compiler не отключён. Числовые/строковые ключи графика не сериализуют функцию в текст. Регистрация node:test явно помечена `void`, как в остальных тестах проекта.

`npm run test:planner` использует два параллельных процесса: это ограничивает взаимное вытеснение CPU у тестов решателя с настоящим временным бюджетом. Не увеличены production-бюджеты и не ослаблены assertions. Отдельные стресс-проверки всё ещё проверяют истечение бюджета.
