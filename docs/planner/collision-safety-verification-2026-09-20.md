## Проверяемые сценарии

Встречный курс; догон; пересечение между кадрами; набор/снижение; безопасные разные высоты и времена; временная неопределённость; геофизический подвес; занятая площадка до взлёта/после посадки/между вылетами; узкое отверстие и коридор; временные границы 4D; искажение времени, высоты и координат экспорта.

Независимый тестовый оракул перебирает 256 детерминированных пар по 2001 временному отсчёту. Аналитическая проверка не пропускает найденные оракулом опасные сближения; отдельный тест ловит столкновение между отсчётами. Геометрический оракул отдельно измеряет расстояние между полными рёбрами. Случайная выборка сама по себе не доказывает корректность для всех входов.

## Воспроизведение

```powershell
npm run typecheck
npm run test:planner
docker compose -p lct -f compose.planner.yaml up --build -d
node --experimental-transform-types --experimental-test-isolation=none --test tests/acceptance/track5-readiness.test.ts
node --experimental-transform-types scripts/verify-collision-safety.ts http://127.0.0.1:3016 output/collision-safety
node --experimental-transform-types scripts/verify-collision-incident.ts output/playwright/collision-safety/obstacle/original-evidence.json output/playwright/collision-safety/obstacle/incident.json output/playwright/collision-safety/obstacle/incident-verification.json
```

Последняя команда сохраняет результаты всех девяти демонстраций и отрицательного примера общей площадки, пакеты KML/GeoJSON, отдельные проверки доказательств и SHA-256 исходников. HTTP 200 не означает допустимость миссии.

Браузерный скрипт: `scripts/verify-collision-browser.js`, запуск через Playwright CLI в отдельном профиле. Начальные URL: `/planner?safety-case=obstacle`, `wind` или `crash`. Для каждого — новый профиль, чтобы остаточный заряд и незавершённый аварийный сценарий не подменялись сбросом состояния. Дождитесь появления `browser-report.json` перед закрытием профиля: CLI может вернуть управление до завершения сохранения скачанного файла. Журнал события и исходные доказательства скачаны отдельными действиями в интерфейсе; первая из двух команд проверки выше генерирует API-пакеты, но не браузерные журналы. Снимки и журнал: `output/playwright/collision-safety/`.

## Что нельзя заявлять

Результат относится к входным координатам, высотам, ветру, ресурсам и допускам модели. Нет подтверждения реальной телеметрии, DEM, внешних БВС, самолётных манёвров, сертификации или разрешения воздушного пространства. Кратчайший аварийный уход из каждой точки и автоматическое продолжение съёмки после отказа не доказаны. Рабочая версия поддерживает проверяемую мультироторную модель; 201/самолёт не выдаётся за поддержанный коптер.

Безопасное выполнение и обязательные работы имеют приоритет над красивым оптимумом. [Точные требования встречи, посадочная достижимость и нормативные оговорки](collision-safety-requirements-2026-09-20.md). Число пройденных тестов не переводится в 100 конкурсных баллов.
