# Browser QA · mission showcase 0.3.0

Реальный Chromium через Playwright CLI, отдельная сессия `showcase-features-030`, локальный Docker API `127.0.0.1:3016`. Финальный прогон 17 сентября 2026: **11/11 групп, 59/59 проверок, 4/4 UI POST HTTP 200, 0 page errors**. Полный отчёт, входы и ответы расчётов: `browser-report.json`.

Проверены:

1. Девять карточек, первый сценарий с настоящим trade-off, явная учебная оговорка, предпросмотр без изменения черновика.
2. Паспорт/MD и Save As; коллизия ID отклонена; исходный документ и ревизия 1 сохранены в выгруженной библиотеке.
3. Два legacy-варианта и реальный третий balanced между ними по обеим метрикам; выбор, явное подтверждение и download JSON/GeoJSON/evidence с формулой 50/50.
4. Добавление и редактирование Custom, ручная группа из двух БВС, удаление профиля с очисткой только его АКБ/назначения.
5. Предпросмотр импорта флота: коллизия блокирует добавление; корректный пакет добавляет все 3 профиля и 18 АКБ без скрытого назначения работ.
6. GeoJSON с отверстием импортирован как препятствие 0–40 м; высота и внутренний контур сохранены.
7. Импорт 4D-объёма сохраняет интервал и высоту 200 м; объединённый вход с препятствием рассчитан реально и остаётся выполнимым в модели.
8. Облака 80 м при запасе 50 м вызывают настоящий CLOUD_CEILING fail; подтверждение недоступно, balanced не предлагается.
9. Явное отключение optional environment удаляет блок из входа и восстанавливает выполнимый модельный расчёт.
10. Desktop 1440×960 и mobile 390×844 без горизонтального overflow; мобильный паспорт помещается и центрирован. Скриншоты сравнения и мобильных экранов просмотрены визуально.
11. Слияние координатных областей сверх 200 КиБ отклонено целиком: диалог остаётся открытым с ошибкой, до/после выгружен одинаковый документ.

`balanced.evidence.json` и `height-and-4d.evidence.json` дополнительно проверены отдельным CLI `verify-mission-evidence.ts`; оба `passes-declared-model`, без fail. Неизвестные модельные проверки сохранены, а не скрыты. Отчёты: `balanced.independent.json`, `height-and-4d.independent.json`.

Первый прогон остановился после трёх успешных групп из-за ошибки QA-селектора: `getByLabel(... exact)` у `select` включал в текст label все option. Селектор исправлен на доступную роль `combobox`, подтверждённую свежим DOM snapshot. Это не дефект приложения. `browser-report-attempt1.json` и `failure-attempt1.png` сохранены; никаких сетевых retries или mock не было. Исправленный полный прогон выполнен заново.

Границы: синтетический функциональный корпус, не стресс-тест, не сертификация стабильности runtime, не доказательство глобальной оптимальности, реального износа, качества съёмки или допуска к полёту. Проверщик evidence использует общие библиотеки геометрии. Все изменения библиотеки сделаны только через UI своей изолированной QA-сессии; тестовые записи сохранены. Исходники UI не менялись.
